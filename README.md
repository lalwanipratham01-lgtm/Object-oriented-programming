## Programs

### C++ Fundamentals

Exercises covering core C++ syntax, console input and output, data types, strings, and different methods of passing arguments to functions.

| Filename                             | Description                                                   |
| ------------------------------------ | ------------------------------------------------------------- |
| `basic_output.cpp`                   | Printing output using `cout`                                  |
| `input_and_addition.cpp`             | Accepting two numbers and displaying their sum                |
| `variable_data_types.cpp`            | Exploring variable declarations and fundamental data types    |
| `rectangle_area.cpp`                 | Computing a rectangle’s area from user-provided dimensions    |
| `largest_in_list.cpp`                | Identifying the largest value in a collection of numbers      |
